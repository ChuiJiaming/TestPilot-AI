## Shared page coverage

1. Dashboard: organization/project/date filters, Run trends, failures, cost, queue and Worker health.
2. Project/environment: membership, roles, environments, SecretRef metadata, network policy, health check.
3. Tests: generation, DSL editor, versions/diff, suites, plans, schedule and browser matrix.
4. Run console: durable status, steps, Agent summary, browser preview, evidence, pause/resume/cancel, approval.
5. Reports/defects/visual: report facts, occurrences, artifacts, baseline and diff, asynchronous export.
6. Settings/operations: tokens, integrations, notification preferences, quotas, audit, usage and service health.

Every page must cover loading, empty, no permission, error, retry, and success states. Shared cross-module gates include Q-022 deployment/SSE; Q-023 database fresh/upgrade/rollback; Q-024 Worker isolation/drain; Q-025 database/object-storage restore.

## Contract reconciliation register

- Confirmed M01: invite acceptance is one-time and requires exact verified-email match; org invite creation is restricted to `org_admin`, project invite creation to `org_admin` or scoped `project_admin`; expiration timestamp is explicit because no default TTL was selected. API token scopes come from the OpenAPI permissions registry, plaintext is returned only on create/rotate, and only hashes are persisted. Access token lifetime is 15 minutes; refresh session is 30 days; cookie is HttpOnly Secure SameSite=Lax with Origin allowlist.
- Confirmed M03: snapshots use highest-numbered non-retired SecretRef version. SecretRef stores opaque external provider version identifiers only.
- Owner-confirmed security restriction: organization-bound API tokens reject global `organization:create` and `platform:admin` permissions because their schema carries exactly one `organization_id`.

The operation-level inventory can be regenerated with `python -m apps.api.scripts.report_runtime_api_coverage`. Its test-source references do not prove acceptance; request/response, status, permissions, database behavior, frontend entry point and acceptance evidence still need module-level review for every operation.

- M04's canonical generation create path and deprecated compatibility alias now appear in both runtime and OpenAPI; generation history/cancel/retry/accept remain additive candidates pending unified contract validation.
- M06 prose has schedule pause/resume; candidate contract has enable/disable/trigger.
